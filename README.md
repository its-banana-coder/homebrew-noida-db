# homebrew-noida-db

Homebrew tap for [noida-db](https://github.com/its-banana-coder/noida-db).

```sh
brew install its-banana-coder/noida-db/noida-db
```

`Formula/noida-db.rb` is regenerated automatically by noida-db's own release
workflow on each tagged release (see `scripts/update-homebrew-formula.sh` in
the main repo) and opened here as a pull request for review.
